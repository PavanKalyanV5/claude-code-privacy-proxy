What leaves your machine, and what comes back

The model reasons about labels. Your tools receive reality.

1 · You type

I'm Jane Q. Testerson,
jane@example.com
+1-555-0142
C:\Users\jtesterson\proj
const port = 8080;
Plus what you never typed: username, hostname, timezone, OS build, locale — added by the tool.
→

2 · Local proxy 127.0.0.1

redact  → literals + patterns
alias   → username, paths
normalize → timezone, locale
headers → strip fingerprints
Plain HTTP to loopback.
No TLS interception, no CA.
→

3 · The API receives

I'm [PII:personal:a1b2c3d4],
[PII:email:9f8e7d6c]
[PII:phone:1a2b3c4d]
C:\Users\example-user\proj
const port = 8080;
Your code is untouched. Only the data about you changed.
↩
Coming back: the model asks to edit C:\Users\example-user\proj — your Edit tool receives C:\Users\jtesterson\proj. Nothing breaks.
Why the labels are hashes, not random tokens. Each label is HMAC-SHA256(key, value), so the same value always produces the same label. A random token per occurrence would change the prompt prefix on every request and silently destroy prompt caching — your bill would multiply and you would never connect it to your privacy tool.
