Why this is the failure mode that matters. A crash is loud — you notice, you fix it. A tool that says PROTECTED while data leaks is quiet, and it stops you looking. That is strictly worse than having no tool at all. So the design rule became: anything unverifiable reports as NOT protected, never "probably fine".
